## What You'll Find Here

This site is split into three main sections:

### 🧑‍💻 Portfolio

The main page is a live snapshot of who I am as an engineer. It features:

- **About** — a quick summary of my background and experience
- **Tech Stack** — tools and frameworks I use daily
- **Work Experience** — client projects I've shipped professionally
- **Personal Projects** — side builds I'm most proud of
- **GitHub Contributions** — my open-source activity heatmap
- **Education & Certifications** — academic background

### 📝 Blog

This is where I write about real things I've built — architecture decisions, hard problems I've solved, and things I've learned by shipping. No beginner tutorials. No filler content.

You can also:
- Subscribe via **RSS** at `/rss`
- Read any post in raw Markdown by appending `.md` to the URL

### 📦 Products

A dedicated section for production apps I've built and publicly launched — currently featuring **ForgeDock** and **ShopFlow**.

## Tech Stack

This portfolio itself is built with:

- **Next.js 15** (App Router + Server Components)
- **Tailwind CSS v4**
- **shadcn/ui** component primitives
- **MDX** for this blog
- **Vercel** for hosting & analytics

## Source Code

The source is available on [GitHub](https://github.com/surajshegukar/dev-portfolio). Feel free to explore, fork, or use it as inspiration — just swap out my personal data with yours.
